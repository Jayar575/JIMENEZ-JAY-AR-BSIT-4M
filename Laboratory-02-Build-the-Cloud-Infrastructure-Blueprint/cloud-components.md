Checkpoint 3 – Identify Cloud Infrastructure Components
Using your observations and the concepts discussed in Chapter 2, identify examples of the following infrastructure components found in your Linux environment:
•	Compute Resources 
-Compute resources allow the server to process commands and run programs. The CPU handles instructions and calculations, while RAM temporarily holds the data needed by active programs.
•	Storage Resources 
-Storage resources keep the operating system, programs, documents, settings, and other important data. Unlike RAM, disk storage is designed to hold files for a longer period.
•	Networking Resources 
-Networking resources allow a server to connect and exchange data with other computers, servers, and online services.
•	Operating System 
-The operating system controls the hardware and software resources of the server. It allows users to manage files, run commands, install applications, and monitor system processes.
For each component:
•	Describe its purpose. 
•	Explain why it is important in cloud computing. 
-The performance of a cloud server depends on its CPU and memory. Cloud providers can adjust these resources based on the requirements of the system or application.
•	Relate it to the Linux environment provided by KillerCoda. 
-KillerCoda gives the Linux server virtual CPU cores and memory. These resources allow users to run commands and perform different activities. CPU details can be checked using lscpu or nproc, while memory information can be viewed using free -h.
