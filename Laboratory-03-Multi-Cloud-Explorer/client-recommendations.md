# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Cloud Platform: AWS

AWS is a good choice for a startup because it offers flexible and scalable cloud services that can grow with the application. The company can start with a small amount of computing resources and increase them as the number of users grows. AWS also provides many services that can help reduce the need to maintain physical servers. This makes AWS suitable for a startup with a limited budget and plans for rapid growth.

### Recommended Services

- **Amazon EC2** – Provides virtual servers for running the mobile application's backend.
- **Amazon S3** – Stores application files, images, videos, and other data.
- **Amazon RDS** – Provides a managed relational database for application data.
- **Amazon CloudFront** – Delivers content quickly to users around the world.

## Client B – University

### Recommended Cloud Platform: Microsoft Azure

Microsoft Azure is the best choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, making migration and identity management easier. The university can connect its existing on-premises systems with Azure while gradually moving selected services to the cloud. This can reduce migration complexity and provide a familiar environment for administrators.

### Recommended Services

- **Azure Virtual Machines** – Runs Windows Server workloads in the cloud.
- **Microsoft Entra ID** – Provides cloud-based identity and access management.
- **Azure Active Directory Domain Services** – Supports applications that require domain-based authentication.
- **Azure Blob Storage** – Stores documents, backups, and other university data.

## Client C – AI Research Company

### Recommended Cloud Platform: Google Cloud Platform (GCP)

Google Cloud Platform is a strong choice for an AI research company because of its powerful artificial intelligence and machine learning capabilities. GCP provides specialized infrastructure and services that can support high-performance computing and machine learning workloads. The company can use Google's AI tools to develop, train, and deploy machine learning models. GCP also provides managed Kubernetes services for scalable AI applications.

### Recommended Services

- **Google Compute Engine** – Provides scalable virtual machines for high-performance computing workloads.
- **Vertex AI** – Provides tools for building, training, and deploying machine learning models.
- **Google Kubernetes Engine (GKE)** – Provides managed Kubernetes for containerized AI applications.
- **Cloud Storage** – Stores large datasets, models, and research files.

## Client D – Global E-Commerce Company

### Recommended Cloud Platform: AWS

AWS is a suitable choice for a global e-commerce company because it provides highly available and scalable infrastructure. The company can distribute its application across multiple geographic regions and use automatic scaling to handle changes in customer traffic. AWS also provides services for content delivery, databases, storage, and load balancing. These capabilities can help maintain application availability during periods of high demand.

### Recommended Services

- **Amazon EC2** – Provides scalable computing resources for the e-commerce application.
- **Amazon EC2 Auto Scaling** – Automatically increases or decreases computing resources based on demand.
- **Elastic Load Balancing** – Distributes incoming traffic across multiple servers.
- **Amazon S3** – Stores product images, files, and other objects.
- **Amazon CloudFront** – Delivers website content quickly to customers around the world.
