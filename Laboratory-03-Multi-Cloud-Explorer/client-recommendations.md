# Checkpoint 4 – Cloud Platform Recommendation Challenge

## CloudNova Technologies

CloudNova Technologies has received requests from four different clients. Each client has different business requirements, so the recommended cloud platform is selected based on factors such as scalability, existing technology, performance, availability, and business needs.

---

## Client A – Startup Company

### Recommended Cloud Platform: Amazon Web Services (AWS)

AWS is a good choice for the startup because it provides flexible and scalable cloud services. The company can begin with a small amount of computing resources and increase them as the number of users grows. AWS also provides many services that can support mobile applications without requiring the company to purchase and maintain physical servers. This makes AWS suitable for a startup with a limited budget and plans for rapid growth.

### Recommended Services

- **Amazon EC2** – Provides virtual servers for running the application's backend.
- **Amazon S3** – Stores images, files, videos, and other application data.
- **Amazon RDS** – Provides a managed relational database for application data.
- **Amazon CloudFront** – Delivers application content quickly to users around the world.

---

## Client B – University

### Recommended Cloud Platform: Microsoft Azure

Microsoft Azure is the best choice for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies and can make cloud migration easier. The university can connect its existing infrastructure to Azure and gradually migrate selected services to the cloud. This allows the university to maintain compatibility with its current Microsoft environment while taking advantage of cloud computing.

### Recommended Services

- **Azure Virtual Machines** – Runs Windows Server workloads in the cloud.
- **Microsoft Entra ID** – Provides identity and access management for users and applications.
- **Azure Blob Storage** – Stores university documents, backups, and other files.
- **Azure Virtual Network** – Connects and secures cloud resources and university systems.

---

## Client C – AI Research Company

### Recommended Cloud Platform: Google Cloud Platform (GCP)

Google Cloud Platform is a strong choice for the AI research company because it provides powerful artificial intelligence and machine learning capabilities. GCP offers high-performance computing resources that can support demanding AI and machine learning workloads. The company can use specialized services to develop, train, and deploy machine learning models. GCP also provides managed Kubernetes services that can be used to build and scale containerized AI applications.

### Recommended Services

- **Google Compute Engine** – Provides scalable virtual machines for high-performance computing workloads.
- **Vertex AI** – Provides tools for developing, training, and deploying machine learning models.
- **Google Kubernetes Engine (GKE)** – Provides managed Kubernetes for containerized AI applications.
- **Google Cloud Storage** – Stores large datasets, research files, and machine learning models.

---

## Client D – Global E-Commerce Company

### Recommended Cloud Platform: Amazon Web Services (AWS)

AWS is a suitable choice for the global e-commerce company because it provides highly available and scalable infrastructure. The company can use multiple AWS Regions and Availability Zones to improve application availability for customers around the world. AWS Auto Scaling can automatically increase or decrease computing resources based on customer demand. Load balancing and content delivery services can also help maintain fast and reliable performance during periods of high traffic.

### Recommended Services

- **Amazon EC2** – Provides scalable computing resources for the e-commerce application.
- **Amazon EC2 Auto Scaling** – Automatically adjusts computing capacity based on demand.
- **Elastic Load Balancing** – Distributes incoming traffic across multiple servers.
- **Amazon S3** – Stores product images, files, and other objects.
- **Amazon CloudFront** – Delivers website content quickly to customers worldwide.

# Checkpoint 6 – Multi-Cloud Decision Matrix

The following decision matrix recommends the most appropriate cloud platform based on different business requirements.

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | AWS provides flexible and scalable services that allow startups to begin with smaller resources and expand as their applications grow. |
| Enterprise Organization | AWS | AWS offers a broad range of services, global infrastructure, security features, and scalability suitable for large organizations. |
| Microsoft Environment | Microsoft Azure | Azure provides strong integration with Windows Server, Microsoft 365, Active Directory, and other Microsoft technologies. |
| AI / Machine Learning | Google Cloud Platform | GCP provides strong AI and machine learning services such as Vertex AI and supports high-performance computing workloads. |
| Kubernetes Deployment | Google Cloud Platform | GCP provides Google Kubernetes Engine (GKE), a managed Kubernetes service designed for deploying and scaling containerized applications. |
| Global Web Application | AWS | AWS provides global infrastructure, load balancing, automatic scaling, and content delivery services for highly available web applications. |

## Summary

The best cloud platform depends on the specific requirements of an organization. AWS is a strong choice for startups, enterprises, and global applications because of its broad range of services and scalability. Microsoft Azure is especially suitable for organizations that already use Microsoft technologies. Google Cloud Platform is an excellent choice for artificial intelligence, machine learning, data analytics, and Kubernetes-based applications.
