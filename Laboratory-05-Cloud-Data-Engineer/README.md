# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory activity focused on understanding cloud data storage, particularly object storage. I used Docker to deploy a MinIO storage server and explored how it can be used to store and organize different types of files. The activity also gave me practical experience with Linux commands, Docker, and basic cloud storage concepts.

## Objectives

* Learn the basic concepts of object storage.
* Set up a MinIO storage server using Docker.
* Access the MinIO web interface.
* Create and manage a storage bucket.
* Understand how object storage can handle a large number of files.
* Practice using Linux and Docker commands.
* Learn how storage systems can protect data from possible failures.

## Tools Used

* **Linux** – Used to execute commands and manage files through the terminal.
* **Docker** – Used to run and deploy the MinIO server.
* **MinIO** – Used for creating and managing object storage.
* **Web Browser** – Used to open and interact with the MinIO web console.
* **Terminal** – Used for running Linux and Docker commands.

## Skills Learned

During this laboratory, I learned how to set up an object storage server using Docker and access it through a web browser. I also learned how to create buckets and manage files using MinIO. In addition, I improved my ability to use Linux commands and work with Docker containers. This activity helped me better understand how cloud storage works and how it can be used to manage large amounts of data.
